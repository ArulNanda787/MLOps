# MLOps Agile Demo — Iris Classification

## Objective
Demonstrate Agile methodology and the Scrum framework through
an Iris flower classification project.

## Technology
- Python
- Scikit-learn
- Decision Tree Classifier
- Joblib

## Execution
Activate the virtual environment and run:

python src/iris_demo.py

## Scrum Activities
1. Scrum team formation
2. Product Backlog creation
3. Sprint Planning
4. Daily Scrum
5. Model development and testing
6. Sprint Review
7. Sprint Retrospective

## Deliverables
- Python source code
- Trained model
- Product Backlog
- Sprint Backlog
- Daily Scrum record
- Sprint Review
- Sprint Retrospective
